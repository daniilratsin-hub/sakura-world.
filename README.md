# Sakura World website

1. Create a GitHub repository named `sakura-world`.
2. Upload all files and the `assets` folder contents preserving folder structure.
3. Open Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Replace `ВПИШИ_IP_СЕРВЕРА` and `ВПИШИ_ВЕРСИЮ` in `index.html` and `about.html`.

The shop is a visual mockup only. Product buttons do not charge money or issue game items. A real store requires a payment provider that supports your account and a secure server-side callback/API integration. Never put bank-card details or secret API keys in public HTML/JavaScript. Because the owner is under 18, involve a parent/guardian and confirm payment provider eligibility before accepting payments.
